# 🐍 Python — Nível Iniciante

> Repositório dedicado ao aprendizado e prática dos fundamentos da linguagem Python, com exercícios e scripts organizados por tema.

---

## 📌 Sobre o Projeto

Este repositório reúne os meus estudos iniciais em Python. O objetivo é consolidar os conceitos fundamentais da linguagem através de exercícios práticos, indo desde a sintaxe básica até estruturas de dados e funções.

---

## 📂 Estrutura do Repositório

```
Nivel_iniciante/
├── variaveis/          # Tipos de dados e declaração de variáveis
├── operadores/         # Operadores aritméticos, lógicos e relacionais
├── condicionais/       # Estruturas if, elif, else
├── lacos/              # Laços for e while
├── funcoes/            # Definição e uso de funções
├── listas/             # Manipulação de listas
├── dicionarios/        # Dicionários e pares chave-valor
└── exercicios/         # Desafios e exercícios práticos
```

> ⚠️ A estrutura pode variar conforme novos arquivos são adicionados.

## 🧠 Conceitos Abordados

| Tema                  | Descrição                                          |

## 🚀 Como Executar

### Pré-requisitos

- [Python 3.x](https://www.python.org/downloads/) instalado

### Rodando um script

```bash
# Clone o repositório
git clone https://github.com/Pedr0165/Python-.git

# Acesse a pasta
cd Python-/Nivel_iniciante

# Execute qualquer script
python nome_do_arquivo.py
```
